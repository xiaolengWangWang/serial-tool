# CommBox v0.8.6

Windows x64，解压后运行 CommBox.exe，无需安装。

## 本版变化

- 修复托盘图标缺失及最小化后无法恢复主窗口；图标缓存不可用时仍可打开工具窗口。
- 优化窄窗口、AI 助手与发送区布局，减少控件挤压和横向滚动。
- 修复统计刷新导致下拉框自动收起，减少收发时的界面重排。
- 修复 HTTP URL 被隐藏端口改写、HTTP 请求按 HEX 发送，以及网络连接被隐藏串口参数阻断。
- 修复浏览器多行 cURL 导入，兼容 LF / CRLF 续行并保留引用内请求体。
- 完善发送校验与错误提示、报文选择及重发操作，修复校验与转换窗口关闭后无法重开。
