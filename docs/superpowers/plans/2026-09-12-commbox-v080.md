## Global Constraints

- AI 默认关闭，不影响任何本地通信与本地分析功能。
- 一个 Serial COM 端口映射一个 TCP 监听端口；Serial COM 只打开一次，映射后的 TCP 监听端口允许同时运行多个独立 TCP Connection。
- 同一个客户端 IP 允许创建多个 TCP Connection，不按 IP 去重。
- 暂停 GUI 刷新，但继续接收数据、继续发送数据、继续 SQLite 存储。
- cURL 解析后由 CommBox HTTP Client 发起请求，不直接调用系统 shell。
- 定时间隔最小 10 ms。
- 不得混淆程序计算结果和 AI 推测；无法可靠配对的响应不能伪造响应时间。
- Existing database analysis limits remain 1,000,000 selected records, 8 MiB payload, 20 detailed samples, 512 preview bytes and 30-second query timeout. Full aggregate scans must state coverage and truncation.
- Ponytail full: reuse existing code and native controls, no new dependency unless necessary; retain explicitly requested functionality. No unrelated rewrite.
- Worktree only; no push, external AI calls, production device connections or system driver installation for validation.
- Use GOMODCACHE=/Users/xiaoleng/Library/Caches/CommBox/go-mod for every Go command; use temporary test databases, never live user data.
- Meaningful regression tests for new logic; baseline failures must be separated from regressions. Do not replace behavioral tests with source-string checks.
