# macOS GUI 优化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按参考截图优化 macOS 主窗口的布局、报文浏览和发送区交互。

**Architecture:** 保留 `desktop/app.m` 的 Cocoa 壳与 `desktop/main.go` 的 CGo 桥接；仅增加报文展示所需的结构化 UI 数据和最小桥接字段，不改 `internal/wincore` 的通信协议。

**Tech Stack:** Objective-C/Cocoa、Go、CGo、现有 SQLite 存储。

**Spec:** `docs/superpowers/specs/2026-09-09-macos-gui-design.md`

## Global Constraints

- 仅修改 macOS UI 与必要的桥接数据，不引入新 GUI 框架或依赖。
- 连接、发送、SQLite 存档和虚拟串口行为保持兼容。
- `go test ./...` 与 macOS `go build ./desktop` 必须通过。
