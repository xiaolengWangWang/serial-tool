# CommBox v0.7.0 ponytail 开发计划

## 目标

完成离线优先的数据分析 MVP，并为 DeepSeek 保留安全、显式调用入口。

## 执行顺序

1. 共享分析核心：Modbus RTU/TCP、TCP/UDP、CRC、异常码和单元测试。
2. 数据区选择：多选、全选、取消选择、反选、当前过滤范围统计。
3. 分析入口：分析选中数据、分析当前可见数据，结果不覆盖原始报文。
4. 数据类型：INT/FLOAT 与 ABCD/BADC/CDAB/DCBA 推荐值。
5. DeepSeek：设置页、Key 安全存储、默认关闭、请求前确认和 16KB 限制。
6. 验收：模拟 TCP/UDP/Modbus 设备、macOS Universal、Linux amd64；仅发布 macOS/Linux。

## 本阶段验收

- 全选只选择当前过滤后的可见记录。
- Cmd+A 使用系统表格全选；按钮提供全选/取消/反选。
- 选择统计显示总数、RX、TX 和字节数。
- 本地分析失败不影响收发。
- `go test ./...` 和 macOS/Linux 构建通过。

## 非目标

- 不默认调用 DeepSeek。
- 不上传全部历史数据。
- 不修改 Windows 代码或发布 Windows 包。
