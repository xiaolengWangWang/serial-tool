# CommBox AI 分析 GUI 优化设计

## 设计目标

让现场用户能快速判断“是否需要 AI”，并始终先完成本地分析；AI 不应隐藏通信数据范围、上传内容或当前配置状态。

## 主流程

```text
选择数据范围
  ↓
本地分析（始终可用）
  ↓
查看统计与异常
  ↓
预览将发送的数据
  ↓
AI 深度分析（主动确认）
```

## 分析中心布局

```text
┌─────────────────────────────────────────────────────────────┐
│ CommBox 分析中心                              [关闭]        │
├─────────────────────────────────────────────────────────────┤
│ 分析范围                                                     │
│ [当前数据区 ▼]  记录 1286  RX 643  TX 643  428 KB          │
│                                                             │
│ [本地分析]        [AI 深度分析]                             │
│ 状态：本地分析可用 / AI 未启用 / AI 已启用                  │
├─────────────────────────────────────────────────────────────┤
│ 分析结果                                                     │
│ 协议、功能码、CRC、异常码、响应时间、数据类型                │
├─────────────────────────────────────────────────────────────┤
│ AI 请求预览                                                  │
│ 将发送：HEX、RX/TX、本地分析摘要                             │
│ 不发送：IP、设备名、主机名                                   │
│ 数据量：6.2 KB / 上限 16 KB                                  │
│                         [取消] [确认并发送]                   │
└─────────────────────────────────────────────────────────────┘
```

## 分析范围

- 当前数据区：当前搜索、方向、类型、长度、时间过滤后的可见数据。
- 选中数据：用户单选、多选、全选、反选后的数据。
- 当前会话：后续版本扩展，不在本轮默认入口显示。
- 超过 16KB 时禁止直接发送，提供“仅异常 / 仅请求响应 / 分段分析”。

## 本地分析结果

使用结构化卡片显示：

```text
协议：Modbus RTU
状态：警告
请求/响应：12 / 12
CRC 错误：2
平均响应：52 ms
异常响应：1
Float32 候选：ABCD = 200.0
```

## AI 状态

按钮状态必须明确：

- `AI 未启用`：点击后打开设置，不发请求。
- `Key 未配置`：点击后打开设置，不发请求。
- `AI 可用`：进入发送预览，不直接请求。
- `分析中`：后台执行，按钮禁用，可取消后续实现。
- `分析失败`：保留本地分析结果并显示原因。

## AI 设置页

入口：`设置 → AI 增强分析`。

```text
启用 AI                 [关闭]
Provider                DeepSeek
API Base URL            https://api.deepseek.com
模型                    deepseek-chat
API Key                 ********（已配置）
超时                    30 秒
最大数据量              16 KB
```

API Key 保存于本地 SQLite 的独立设置库，不显示明文，不写日志，不进入 Git。

## 现场安全与体验

- 离线时本地分析完全可用。
- AI 默认关闭、Key 默认为空。
- AI 请求在后台线程执行，不阻塞收发。
- 默认只发送 HEX、方向、时间戳和本地摘要。
- IP、设备名、主机名默认不发送。
- 每次 AI 请求前显示范围和数据量。
- 不自动逐条调用、不自动重试、不静默截断。

## 实施顺序

1. 将现有“分析中心”改为范围统计 + 本地分析结果页。
2. 增加 AI 状态展示和未启用引导。
3. 增加请求预览确认区。
4. 接入取消/超时和错误回退。
5. 用模拟 Modbus/TCP/UDP 数据验收现场流程。
