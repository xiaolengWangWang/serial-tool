# v0.7.0 本地数据类型分析设计

## 目标

帮助现场人员在没有网络和设备点表不完整时，快速查看报文中的常见数值候选；结果仅为候选，不作为协议结论。

## 规则

- 2 字节显示 UInt16 的 BE/LE 值。
- 4 字节显示 UInt32 和 Float32 候选值。
- Float32 支持 ABCD、BADC、CDAB、DCBA 四种字节序。
- NaN 和 Infinity 不显示。
- 原始 HEX 和本地协议分析结果始终保留。
- 不自动调用 AI，不上传数据。

## 验收

- `43 48 00 00` 的 ABCD Float32 候选为 200。
- 16 位和 32 位整数结果与标准字节序一致。
- 分析失败不影响通信。
- `go test ./...`、macOS 和 Linux 构建通过。
