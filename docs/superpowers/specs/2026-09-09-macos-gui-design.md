# macOS GUI 优化设计

## 目标

将 macOS 主窗口调整为截图所示的紧凑、原生、信息优先布局，同时保留现有通信能力和 Cocoa 实现。

## 范围

- 左侧：连接配置、模式/角色、地址参数、连接状态、历史连接。
- 右侧：接收数据与日志页签、报文表格、搜索和方向/类型/长度/时间过滤。
- 底部：发送数据与定时发送页签、HEX 发送、循环发送、行尾、间隔和操作按钮。
- 保留现有工具箱、监控窗口、虚拟串口窗口和 Go 核心引擎接口。

## 约束

- 仅修改 macOS UI 与必要的桥接数据，不引入新 GUI 框架或依赖。
- 连接、发送、SQLite 存档和虚拟串口行为保持兼容。
- 窗口最小尺寸可用，主要区域随窗口伸缩。
- 接收报文继续保留原始字节，并支持 HEX 与 ASCII 展示。

## 验收标准

1. 主窗口视觉层级与截图一致：左侧配置、右侧数据、底部发送。
2. 接收报文可按方向、数据类型、长度和时间筛选，搜索支持 HEX/ASCII。
3. 选中表格行可查看完整报文详情，长报文不撑坏表格布局。
4. 发送一次、定时发送、循环发送、清空和导出操作可用。
5. `go test ./...` 与 macOS `go build ./desktop` 通过。
