# CommBox v0.7.0 数据分析与 AI 页面设计

## 页面结构

主窗口保留连接、收发和实时数据；新增独立“分析中心”窗口，避免分析结果覆盖原始报文。

```text
分析中心
├─ 分析范围：当前数据区 / 选中数据
├─ 范围统计：记录、RX、TX、字节数、完整性
├─ 本地分析
├─ AI 深度分析
└─ 分析结果
```

## 分析范围

- 当前数据区指当前过滤后实际显示的记录。
- 选中数据支持单选、多选、全选、反选和取消选择。
- 数据量超过 16KB 时，AI 只允许先本地分析；不得静默截断。

## 本地分析

离线始终可用，支持 Modbus RTU/TCP、TCP/UDP、CRC、功能码和异常码。结果显示协议字段、异常和现场排查建议。

## AI 深度分析

- 默认关闭、Key 默认为空。
- 仅用户点击按钮后调用。
- 请求在后台线程执行，超时 30 秒，不自动重试。
- 发送前使用当前范围的 HEX 和本地分析摘要，默认不发送 IP/设备名。
- Key 保存在本地 `commbox-settings.sqlite3`，不写日志、不进 Git。
- AI 失败只显示错误，不影响收发和本地分析。

## 验收

- 窗口可显示当前/选中范围统计。
- 本地分析离线可用。
- 未启用或无 Key 时 AI 按钮给出明确提示。
- AI 请求不阻塞主界面。
- macOS Universal 与 Linux 构建通过；只发布 macOS/Linux。
