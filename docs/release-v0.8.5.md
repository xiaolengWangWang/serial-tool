# CommBox v0.8.5

Windows x64，解压后运行 CommBox.exe，无需安装。

## 本版变化

- 新增检查更新。帮助菜单可手动检查，启动时也会自动检查一次（设置菜单里可关闭，关掉后完全不联网）。
- 发现新版本时可直接下载安装包，下载完成后按发布说明里的 SHA256 自动校验，不一致就删除并报错。
- 下载地址只认 GitHub 官方域名；检查只发一个 GET，不上传任何本机数据。
- 发布说明改为精简版，只列变化、校验和与注意事项。
