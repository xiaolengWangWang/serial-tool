# CommBox 当前 GUI 设计

版本：0.7.1 开发版

## 1. 主窗口

主窗口默认尺寸：`1040 × 700`

```text
┌──────────────────────────────────────────────────────────────┐
│ CommBox v0.7.x                         操作 / 编辑 / 视图    │
├──────────────────┬───────────────────────────────────────────┤
│ 连接配置          │ 接收数据                                  │
│                  │ 搜索 / 方向 / 类型 / 长度 / 时间过滤       │
│ 工作模式          │                                           │
│ 串口 / TCP / UDP  │ 数据表格                                  │
│ 串口服务器 / HTTP │                                           │
│                  │ 详情 / 选择 / 分析中心                     │
│ 连接参数          ├───────────────────────────────────────────┤
│ 连接状态          │ 发送数据                                  │
│ 连接 / 断开       │ HEX / 行尾 / 历史 / 收藏 / 间隔(ms)        │
│ 历史连接          │ 发送一次 / 开始定时 / 定时高级设置         │
└──────────────────┴───────────────────────────────────────────┘
```

窗口最小尺寸为 `1040 × 700`。放大窗口时，右侧通信工作区自适应，左侧连接配置保持顶部对齐。

## 2. 连接配置区

支持工作模式：

- 串口
- TCP
- UDP
- 串口服务器
- HTTP 客户端

串口参数：

- 串口设备
- 波特率
- 数据位
- 校验位
- 停止位

网络参数：

- 角色：服务端 / 客户端
- IP 地址或监听网卡
- 端口
- 串口服务器协议：TCP / UDP

底部提供：

- 连接状态
- 连接 / 断开按钮
- 历史连接
- 服务端地址提示

## 3. 接收数据区

过滤条件：

- 关键字搜索
- 方向：全部 / RX / TX
- 数据类型：全部 / ASCII / HEX
- 长度：全部 / 1-8 / 9-64 / 65+
- 时间：全部 / 1分钟 / 5分钟 / 30分钟

数据表格字段：

```text
时间 | 方向 | HEX | ASCII | 长度
```

底部基础操作：

```text
[全选] [取消选择] [反选] [分析选中数据] [分析中心]
```

全选范围只包括当前过滤后实际显示的数据，不包括未显示的历史数据。

选择统计显示：

```text
已选择 N 条    RX N    TX N    数据量 N B
```

支持系统表格多选和 macOS `Cmd+A`。

右键菜单：

- 复制 HEX
- 复制 ASCII
- 复制整行
- 本地分析

## 4. 分析中心

分析中心为独立窗口，避免覆盖原始通信数据。

```text
分析中心
├─ 分析范围：当前数据区 / 选中数据
├─ 范围统计
├─ AI 状态
├─ 开始本地分析
├─ AI 深度分析
└─ 详细分析结果
```

范围统计包括：

- 记录数量
- RX 数量
- TX 数量
- 数据量
- 当前可见范围完整性

本地分析支持：

- Modbus RTU
- Modbus TCP
- TCP/UDP IPv4 头
- 源端口和目的端口
- 功能码
- 异常码
- 起始地址和数量
- CRC 校验
- UInt16 / UInt32
- Float32
- ABCD / BADC / CDAB / DCBA

详细分析默认展开前 20 条报文，其余数据保留在范围统计中。

## 5. AI 增强分析

AI 是可选增强能力，不是通信核心依赖。

入口：

```text
操作 → AI 增强分析设置
```

配置项：

- 启用 DeepSeek
- API Base URL
- 模型
- API Key

默认状态：

```text
AI：关闭
API Key：为空
网络请求：不执行
本地分析：正常可用
```

AI 调用流程：

```text
选择当前数据区或选中数据
        ↓
查看本地分析
        ↓
查看发送范围和 HEX 预览
        ↓
用户确认
        ↓
后台调用 DeepSeek
```

现场保护：

- 最大请求数据量 16KB
- 请求超时 30 秒
- 不自动重试
- 不发送 IP、设备名、主机名
- 不记录 API Key
- 不影响本地通信和本地分析
- Key 保存于本地 `commbox-settings.sqlite3`

## 6. 发送数据区

发送内容与定时发送参数放在同一页：

- HEX 发送开关
- 行尾：无 / LF / CR / CRLF
- 发送历史
- 收藏
- 间隔(ms)
- 发送一次
- 开始 / 停止定时

定时发送规则：

- 间隔不能小于 10ms
- 空内容禁止启动
- 非法 HEX 禁止启动
- 定时发送与循环发送互斥
- 运行期间锁定相关控件
- 断开连接时自动停止
- AI 请求不会阻塞定时发送和通信界面
