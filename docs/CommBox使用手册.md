# CommBox 使用手册（v0.8.0）

CommBox 是一款串口 / 网络调试工具：简单、稳定、顺手。支持串口、TCP、UDP、串口服务器、HTTP 客户端与虚拟串口，内置结构化报文表格、筛选、本地分析、数据库存档分析、AI 深度分析与工具箱。

- 适用平台：macOS 桌面版（Apple Silicon / Intel 分别打包）、Linux 命令行（amd64）。
- 本手册以 macOS 桌面版为主，命令行差异见第 12 节。

---

## 1. 安装与启动

### macOS
1. 到 Releases 下载对应芯片的安装包：
   - Apple Silicon（M 系列）：`CommBox-macOS-AppleSilicon-vX.Y.Z.dmg`
   - Intel：`CommBox-macOS-Intel-vX.Y.Z.dmg`
2. 双击 `.dmg` 挂载，把 `CommBox.app` 拖入 `Applications`。
3. 安装包为 ad-hoc 签名，首次打开若被拦截：在 `CommBox.app` 上**右键 → 打开**，或到「系统设置 → 隐私与安全性」点「仍要打开」。

### Linux（命令行）
下载 `CommBox-CLI-linux-amd64-vX.Y.Z`，`chmod +x` 后运行，`--help` 查看用法，`-version` 查看版本。

---

## 2. 主界面速览

窗口默认 1280 × 820，分三区：

- **左侧 · 连接区**：工作模式、串口/网络参数、连接/断开、连接状态、对端信息、最近连接。
- **中部 · 接收数据**：结构化报文表格 + 筛选行 + 选择/分析操作 + 报文详情；下方切「日志」页看系统消息。
- **底部 · 发送数据**：文本/HEX 发送、行尾、收藏/历史，以及「发送数据 / 定时发送」两页。
- 右侧可展开**分析中心**（默认隐藏）。

---

## 3. 建立连接

在左侧「工作模式」选择模式，填参数后点**连接**（⌘L 连接/断开）。

| 模式 | 关键参数 | 说明 |
|---|---|---|
| 串口 | 串口设备、波特率、数据位、校验位、停止位 | 点「刷新」(⌘R) 重新扫描串口 |
| TCP | 服务端/客户端、监听网卡或目标 IP、端口 | 客户端断线自动重连（指数退避，最长 30s） |
| UDP | 服务端/客户端、地址、端口 | 无连接；服务端可回复最近对端 |
| 串口服务器 | 串口参数 + 网络角色/地址 | 串口 ↔ 网络双向透传 |
| HTTP 客户端 | 目标 URL | 方法/路径/头/体在发送区填写 |

- 连接状态区显示：模式、端点、串口参数、运行时间、真实对端；累计 RX/TX 条数与字节、重连、错误计数。
- HTTP 支持 GET/POST/PUT/DELETE/PATCH/HEAD/OPTIONS；方法省略默认 GET；请求体以 `{`/`[` 开头默认 JSON，否则表单；保持 Cookie 会话；不自动跟随重定向。

## 4. 接收数据

### 表格字段
```
时间 | 方向 | HEX | ASCII | 来源 | 长度 | 协议 | 状态 | 响应时间
```
- **来源**：该报文的连接端点（TCP/UDP 对端地址或串口名）。选中某行，详情区还会显示**报文 ID、连接、链路**。
- 每条报文带毫秒时间戳，区分 RX/TX。
- 「协议」为该报文的传输类型（TCP/UDP/SERIAL 等）；「状态」默认「未分析」；普通报文「响应时间」显示 `—`（HTTP 请求耗时已实现，请求/响应自动配对尚未做）。

### 筛选行
搜索 HEX/ASCII、按方向（全部/RX/TX）、类型（全部/ASCII/HEX）、长度（全部 / 1–8 B / 9–64 B / 65 B 以上）、时间（全部 / 近 1 / 5 / 30 分钟）过滤；「重置」清空全部条件。

### 暂停显示（v0.8.0）
筛选行的**「暂停显示」**只**冻结表格画面**，接收与入库**继续运行**；暂停期间按钮显示「继续显示(N)」标明缓冲了多少条，点它恢复并一次性补齐。适合数据刷屏时看某段报文。

### 选择与操作
- 全选 / 取消选择 / 反选（针对当前可见报文），底部显示已选条数与 RX/TX/数据量。
- 右键：复制 HEX / 复制 ASCII / 复制整行 / 本地分析。
- 清空接收区（⌘K）、导出接收数据（⌘E）、ASCII 列开关（⌘⇧H）、监控窗口（⌘⇧M）。
- 内存中报文超过 10,000 条时裁剪到最近 8,000 条；完整历史另存于 SQLite。

### 监控窗口（⌘⇧M）
只显示实时接收流，可「暂停滚动 / 继续滚动」、清空、导出，与主表格独立。

## 5. 发送数据

在底部「发送数据」页：

- **HEX 发送**（默认开）或文本；**行尾**：无 / LF / CR / CRLF。
- 输入框填内容 → **发送一次**（⌘Enter）。HEX 示例：`01 03 00 00 00 02`。
- **历史 / 收藏**：下拉选历史；「收藏当前」保存、「删除」移除收藏。
- **定时发送**（⌘T 开关）：设「间隔(ms)」（不小于 10ms），点「开始定时」；空内容或非法 HEX 不允许启动，发送失败会结束循环。
- 「定时发送」页可设「循环 / 次数（0=一直）」。

---

## 6. 连接管理（v0.8.0，⌘⇧C）

「操作 → 连接管理」打开，专门管理多客户端 / 多对端场景。窗口每秒自动刷新：

- **连接列表**：连接 ID、类型（TCP/UDP）、远端、RX、TX。
- **向选中连接发送**：底部输入 + HEX 开关 + 行尾 + 发送；TCP 服务端可只发给某一个客户端，UDP 为选中对端。输入框下方有**发送前 HEX 校验**（`✓ N 字节 …` / `✗ 原因`）。
- **右键**：向此连接发送 / 断开此连接（UDP 无连接可断开会提示） / 复制连接 ID。
- **策略**：最大连接数（0=不限）；「串口回复最新请求的连接（服务器模式）」——串口服务器把串口回包只发给最近请求的那个连接，而非广播。点「应用策略」生效。

> 说明：接收与入库始终由内核完成，连接管理窗口只是操作与观察入口。

## 7. 报文分析

### 本地分析（离线，无需 AI）
- 单条：表格右键「本地分析」，结果追加到详情区。
- 成批：选中报文点「分析选中数据」，或点「分析中心」展开右侧栏后「开始本地分析」。
- 范围可选「当前数据区 / 选中数据」，输出范围统计 + 逐条分析（最多展开 20 条，其余仍计入统计）。
- 识别项：基础信息（长度/可打印比例/首字节）、Modbus RTU（功能码/异常码/地址数量 + CRC）、Modbus TCP（MBAP）、IPv4 头、数值候选（UInt16 大小端；UInt32/Float32 的 ABCD/BADC/CDAB/DCBA）。属基础字段识别，非完整协议校验。

### 工具箱（⌘⇧B）
CRC16 Modbus、CRC16 CCITT-FALSE、CRC32、XOR、SUM、Base64 编/解码、Unix 时间戳转换。

### AI 深度分析（可选）
1. 先在「操作 → AI 增强分析设置」(⌘⇧I) 配置：启用、Base URL、模型、API Key。默认 DeepSeek（`deepseek-chat`，OpenAI 兼容接口），设置存本地。默认关闭。
2. 在分析中心点「AI 深度分析」，或对选中报文发起：
   - **发送前会弹出可编辑内容**（含报文、传输类型、连接 IP:端口），可删改后再确认发送——隐私可控。
   - 请求在后台执行，不阻塞本地通信；结果以富文本（Markdown 渲染）显示。
3. **继续追问 AI**（⌘⇧K）：在首次分析基础上多轮对话，带上下文。
4. 每次分析与追问自动保存 Markdown 存档；「操作 → 打开 AI 存档目录」查看。
- 限制：首次报文分析 HEX 输入上限 16 KiB；数据库报告发送前按 32 KiB 截断；单次 AI 请求超时 60s。

---

## 8. 数据库存档与分析

- 发送、接收、断开事件自动写入 SQLite；原始字节以 BLOB 保存，附文本、时间戳与会话；按日期与 100 MiB 自动分文件。
- macOS 数据目录：`~/Library/Application Support/CommBox/data`（「视图 → 打开数据库目录」⌘⇧D）。
- **数据库分析**：选择一个或多个 SQLite 文件（⌘/Shift 多选或全选），按开始/结束时间与 ALL/RX/TX 只读查询，统计匹配条数、收发条数与字节，并输出来源文件、时间、方向、连接信息与原始 HEX 摘要。
- 上限：最新记录 1,000,000 条（所选文件合计）、选中原始负载 8 MiB、报告展开 20 条、每条 HEX 预览 512 字节、查询超时 30s。
- 数据库报告也可交给 AI 做深度分析（同样发送前可编辑）。

---

## 9. 虚拟串口映射（⌘⇧V）

「操作 → 虚拟串口映射」把 TCP 端点映射为本地串口，可管理多个映射、后台运行、自动重连；与主连接独立。macOS/Linux 使用 PTY，Windows 依赖 com0com 驱动。

---

## 10. 新建实例与后台运行

- **新建实例**（⌘N）：再开一个独立窗口/进程，便于同时调试多个设备。
- 关闭窗口只是隐藏，连接与虚拟串口在后台继续；从 Dock 点图标可重新唤出。

## 12. 命令行（Linux / CLI）

命令行版共享同一 Go 内核，支持：列出串口、显示版本、配置串口参数、文本/HEX 收发、行尾设置，以及 `vserial` 的 TCP → 虚拟串口映射。它不提供与桌面端完全一致的图形功能，具体参数以 `--help` 为准。

---

## 13. 常见问题

- **连不上串口 / 看不到设备**：点「刷新」(⌘R) 重新扫描；确认设备未被其它程序占用、驱动已装。
- **TCP 客户端频繁断开**：会自动重连（指数退避，最长 30s），状态栏可观察「正在重连…」。
- **数据刷太快看不清**：用「暂停显示」冻结表格（接收与入库不受影响），或打开监控窗口暂停滚动。
- **AI 无法使用**：确认已在 AI 设置里启用并填了 API Key；分析在后台执行，不会卡住通信。
- **发送被拒**：HEX 模式下内容需为合法十六进制；定时间隔不能小于 10ms。
- **历史数据在哪**：SQLite 存于数据目录（⌘⇧D 打开），可用「数据库分析」只读查询。
