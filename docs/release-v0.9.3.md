# CommBox v0.9.3

Windows x64，解压后运行 `CommBox.exe`。发布包附带 VirtualCOM v0.2.0 的图形界面和命令行，无需安装虚拟串口驱动。

## 本版变化

修复网络慢时检查更新失败、下载安装包中途断开只能从头再来的问题。

- 检查更新：连接 GitHub 的等待时间放宽到 TLS 握手 45 秒、单次请求 60 秒，连接失败自动重试一次。此前握手超过 10 秒就报 `TLS handshake timeout`，连 GitHub 慢的网络下几乎每次都失败。手动检查时会提示可能需要半分钟左右。
- 下载安装包：连接中断后从断点接着下，最多尝试 5 次；不再限制总时长，只要还在收数据就继续，60 秒收不到新数据才断开重连。下载完成后照旧核对大小和 SHA256。

v0.9.2 及更早版本仍用旧的超时，网络慢时应用内可能检查不到本版，请到发布页手动下载；从本版起可以正常检查和下载。

## 使用

先运行 `VirtualCOM-GUI.exe` 创建一对端口并保持运行，再打开两个 CommBox 窗口，分别连接两端。命令行使用 `CommBox-CLI.exe -list` 查看端口、`-port COM号` 打开。

## 验证与边界

- 全量 Go 与 Windows GUI 回归测试通过；发布产物逐项校验 PE 头、构建来源 commit、版本资源和压缩包内容。
- 在连 GitHub 很慢的网络上实测（TLS 握手 12~21 秒、下载约 39 KB/s）：检查到最新版本，完整下载 13 MB 安装包并通过 SHA256 校验，用时约 10 分钟。
- 断点续传依赖服务器支持 Range 请求，GitHub 支持；不支持时自动改为从头下载。
- 仍需能访问 GitHub：完全连不上时检查会失败，失败提示里会给出发布页地址，可手动下载。
- VirtualCOM 适配的边界与 v0.9.0 相同：只提供字节流端口，波特率、数据位、校验、停止位和控制信号不生效，未适配的第三方串口软件仍不兼容。
- VirtualCOM 必须保持运行并与 CommBox 位于同一用户登录会话；退出后端口会移除。Windows 10 和长时间运行尚未验收。
- 程序未做商业代码签名。
