# CommBox v0.7.5 连接与数据库优化

## 设计与开发范围

参考用户提供的蓝白 GUI，保留原生 macOS 工作台，不新增界面依赖。

1. 将连接配置、连接状态、对端信息、快捷操作分为独立卡片。
2. 左侧固定宽度，参数按模式自然收缩；高度不足时纵向滚动，不挤压文字。
3. 中央数据区随窗口扩展，默认 1280×820，最小 1040×700；分析中心默认隐藏。
4. 连接状态从核心结构化快照读取，避免一行长文本覆盖连接详情。
5. 合入数据库多文件、百万条上限及真实弹窗防重叠修复，最后进行回归、编译和本地打包。

补充修复：关闭左侧滚动区自动顶部 inset，消除放大窗口后出现的 40 点空白；工作台底色随系统明暗主题重新绘制，避免浅色背景上的浅色文字。

## 连接状态

- TCP 服务端显示“监听中”，客户端数为当前真实连接数。客户端离线不等于监听停止。
- TCP 客户端显示连接状态及真实远端地址；对端卡片最多展示 3 个地址，总数保留。
- UDP（含串口服务器 UDP 模式）显示“已就绪”，明确不代表对端在线。
- HTTP 显示“已就绪”，明确不代表服务可达。
- 连接失败进入错误状态并增加错误计数，不再遗留“正在连接”。主动断开后清除对端信息。
- RX / TX、重连和错误为本次应用运行累计，运行时间属于当前连接。未连接时运行时间为“—”。
- 地址及大数统计可悬停查看完整内容，不用长文本撑大卡片。无真实依据的客户端连接时间不展示。

## 多 SQLite 分析

入口：顶部“数据库分析”，或分析中心“分析数据库”。

- 支持 CommBox 数据目录内 `serial-data-*.sqlite3` 文件，⌘ / Shift 多选，也可全选或取消选择。
- 最新条数提供 100 / 500 / 2,000 / 10,000 / 100,000 / 1,000,000 档位。
- 条数上限为所选文件合计，按真实时间跨文件合并；相同时间按文件名及记录 ID 确定顺序。
- 每个文件采用独立只读快照，采集过程中不保证所有文件是同一瞬间；不同文件里的重复采集记录不会自动去重。
- 全部筛选结果进行条数及字节统计；选中原始负载仍受 8 MiB 上限约束，不截断单条报文。
- 仅展开选中范围时间正序前 20 条完整原始报文详情，其余计入统计。所有省略条数明确显示。
- 使用流式合并和固定 20 条详情缓存，不在 Go 中持有百万条报文对象。
- 任一文件不可读、schema 不兼容或查询超过 30 秒，整个分析明确报错，不静默漏掉文件。
- 本地离线执行，不调用 DeepSeek，不上传数据库或报文。

## 验证方法

```sh
go test ./... -count=1
go test -race -short ./... -count=1
go build -o /tmp/commbox-layout-check ./desktop
COMMBOX_LAYOUT_CHECK_DIR=/已有的临时输出目录 /tmp/commbox-layout-check
```

普通测试包括真实 1,000,001 条 SQLite 记录的边界测试；race short 单独验证并发及小规模业务用例，避免插桩开销使百万条查询超过生产超时。

原生检查覆盖明暗主题 × 客户端/服务端 × 默认/最小/放大/恢复窗口 × 分析中心显隐 × 各连接模式与发送标签，共 480 组；另检查三个窗口宽度下实际数据库 sheet 的跨容器重叠。滚动容器内部卡片、左栏宽度和顶部对齐均纳入断言。

AppKit 离屏缓存预览可辅助检查布局，但部分系统合成控件显示为黑块，不能代替真实屏幕截图。当前环境没有可用的屏幕录制权限；仍需在已启动的应用中检查最终系统渲染效果。

## 交付边界

本次只构建 macOS Universal 应用和 Linux amd64 命令行包，不构建 Windows。发布到 GitHub 为独立操作，不覆盖既有 v0.7.2 Release。

## 本轮验证结果（2026-09-11）

- `go test ./... -count=1`：通过，含百万条真实 SQLite 用例。
- `go test -race -short ./... -count=1`：通过；百万条压力用例在普通测试单独验证。
- 打包后的 macOS Universal 可执行文件：480 组布局检查 0 失败，数据库多选/范围控件及真实弹窗检查通过。
- macOS x86_64 / arm64、Linux amd64 编译通过；macOS 本地 ad-hoc 签名校验、Info.plist 校验通过。Linux 在本机仅交叉编译，未运行 Linux 二进制。
- 修复前回归检查确实捕获：失败连接遗留 Connecting、卡片宽度收缩、顶部 40 点空白；修复后对应断言通过。
