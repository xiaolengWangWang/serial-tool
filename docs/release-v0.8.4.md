# CommBox v0.8.4 — 移除 Windows 虚拟串口、界面重排与字号调整

本次提供 Windows x64 桌面程序，解压后运行 CommBox.exe，无需安装 Go。

本版把未验证通过的 Windows 虚拟串口功能连同内嵌驱动一并移除，并重排 Windows 桌面版布局、放大字号。通信引擎、协议处理与数据存储逻辑未改动。

## 移除虚拟串口（Windows）

com0com 实现三项都没有在真机上验证通过：驱动安装、虚拟串口命名、setupc 命令超时。半成品对外开放只会制造"创建成功却收不到数据"的假象，因此本版删除：

- `internal/wincore/vserial_windows.go` 的 com0com 实现，改为返回"功能开发中"；
- `internal/wincore/install_driver_windows.go` 与内嵌的两个 com0com 安装包（约 517 KB）；
- 主窗口的虚拟串口映射窗口及其添加、停止、复制设备路径、安装驱动五个入口。

菜单保留一项「虚拟串口映射(开发中)」，点击后说明当前状态，并提示需要把 TCP 端点接到串口软件时可先用「串口服务器」模式转发。macOS / Linux 的 PTY 实现不受影响。

程序体积由 16.76 MB 降到 16.01 MB。

## 布局

此前"标签与它的下拉框之间空出一大段"是 walk 的分配规则所致：BoxLayout 把富余宽度按 `权重/组内权重和` 分给能变宽的控件，定了宽度上限的控件拿不走自己那一份，剩下的会被平摊成每个控件之前的位移。本版按这个规则重排：

- 每行只留一个"吃掉富余"的控件：可编辑下拉框与输入框本身是 greedy，其余行改用 `HSpacer` 或把该控件的拉伸权重提到 100（新增 `stretchFill` 常量）。实测行尾、目标、历史、快捷等标签与其控件间距由约 180px 收到 6px。
- 发送区的历史/快捷与定时/循环由一行拆成两行。此前八个控件把该行最小宽度顶到 750px 以上，窗口收窄时文字互相叠压；拆分后每行最小宽度都在 460px 以内。
- 状态栏、数据统计、发送提示、客户端标题改用省略号模式。带省略号的标签在 walk 中可压缩，不再用自身文字宽度顶住整窗最小宽度，运行中数字变长也不会再撑大窗口。
- 选中操作行的标签与按钮各自定宽，窗口收窄时不会再挤到文字重叠。
- 窗口最小尺寸由 1366x746 降到 1102x620 逻辑像素，1080p 与 1366x768 屏幕都能完整显示。
- `createWindow` 拆为 `menus`、`connectionPanel`、`monitorPanel`、`packetTab`、`sendArea` 五个函数，并抽出 `formLabel`、`inlineLabel`、`fixedCombo`、`toolButton` 四个构造器。

## 字体与控件尺寸

- 正文 9pt → 10pt，分区标题 10pt → 12pt，等宽字体 9pt → 10pt。
- 输入框与下拉框统一 28px 行高、按钮 30px；此前不给下限时同一行里 LineEdit 比 ComboBox 矮一截，中文字形上下也几乎贴边。
- 表单标签与右侧输入框垂直居中对齐，文字不再贴在框顶。
- 数据表列宽随字号加宽（时间 95→108、HEX 245→268 等），连接信息区按四行文字留足高度。
- 二级窗口（实时监控、校验与转换、连接管理、HTTP 工作台、历史分析、AI 设置）此前用系统默认 GUI 字体，与主窗口的雅黑并列时字形明显不同，现统一字体、边距与按钮宽度。工具箱标题与菜单项统一为「校验与转换」，HTTP 窗口统一为「HTTP 工作台」。
- AI 面板宽度 258→276px，「发送追问」独占一行，「停止」与「AI 设置」并排，按钮文字不再被边框切掉。
- 状态栏未连接时不再出现 `|  |` 空档位。

## 验证

- Windows 下 `go test ./...`、`go vet ./...`、`gofmt` 与桌面构建均通过。
- 实机截图核对三种尺寸：默认 1243x736、最小 1102x620、最大化 1463x914 逻辑像素，各行均无重叠、无截断，AI 面板展开与串口模式同样核对。
- 通信冒烟测试：UDP 客户端连接 127.0.0.1:9000，外部程序发送 4 帧 `01 03 02 00 7B F8 9E`，数据表与统计、状态栏计数均正确显示（共 4 条 / RX 28 B）。
- 「虚拟串口映射(开发中)」菜单项弹窗文案已核对。

## 已知限制

- Windows 虚拟串口功能未开放，仍在开发中。
- 布局核对在 175% 显示缩放下进行，其他缩放比例未逐项复核。
- 数据表表头中文在等宽字体下字距偏开；表头与单元格无法分别设置字体，而 HEX 列需要等宽对齐，保留当前取舍。
- 本次未构建或验证 macOS / Linux 程序。
- Windows 程序未做商业代码签名，SmartScreen 可能提示未知发布者。
