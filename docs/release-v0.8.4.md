# CommBox v0.8.4

Windows x64，解压后运行 CommBox.exe，无需安装。

## 本版变化

- 移除 Windows 虚拟串口功能与内嵌的 com0com 驱动包：三项关键行为（驱动安装、串口命名、命令超时）未在真机验证通过，菜单只保留「虚拟串口映射(开发中)」说明状态。程序体积 16.76 MB → 16.01 MB。
- 重排界面：修掉标签与输入框之间空出一大段的问题，发送区拆成两行，窗口最小尺寸 1366x746 → 1102x620，窗口放大缩小不再出现文字重叠。
- 放大字号：正文 9→10pt、分区标题 10→12pt、等宽 9→10pt；输入框与按钮统一行高，标签与输入框垂直居中。
- 二级窗口统一字体与边距；工具箱改名「校验与转换」，HTTP 窗口改名「HTTP 工作台」。
