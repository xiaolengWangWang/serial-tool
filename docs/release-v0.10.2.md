# CommBox v0.10.2

本版提供 Windows x64、macOS Apple Silicon / Intel 安装包和 Linux amd64 命令行程序。macOS 的 AI 深度分析改在分析中心内对话；Windows 和 Linux 的功能与 v0.10.1 一致，版本号同步到 0.10.2。

## 本版变化

- macOS 点「AI 深度分析」不再弹出可编辑确认框，直接发送当前范围的报文（当前显示数据库报告时发送这份报告）。不想上传的数据请先用筛选或「选中数据」缩小范围。
- 回答不再打开独立窗口，而是在分析中心的结果区逐段显示；本地分析会切回本地报告，两边内容都保留。
- 结果区下方新增输入框，回车或点「发送」继续追问；回答中「发送」变为「停止」，已生成部分保留。「新对话」在「AI 设置」旁边。
- AI 未启用、Key 未配置或数据超限时，提示显示在 AI 状态行，不再弹窗。
- 流式输出的文字使用正文样式，深色模式下回答过程中也能看清。

## 验证与边界

- macOS 上全量 Go 测试、原生桌面构建通过；AppKit 布局自检在最小窗口（1280×700）下检查分析中心内的 AI 对话区与输入框，共 486 个界面组合，0 个失败。
- 真实 AI 服务的流式对话未在本构建环境中验证。Windows x64 交叉构建通过，未做原生界面验收。
- 程序未做商业代码签名；macOS 使用临时签名。
