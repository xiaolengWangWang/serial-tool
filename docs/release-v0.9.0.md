# CommBox v0.9.0

Windows x64，解压后运行 `CommBox.exe`。发布包附带 VirtualCOM v0.2.0 的图形界面和命令行，无需安装虚拟串口驱动。

## 本版变化

- 新增 VirtualCOM 免驱动适配：在串口列表中发现活动端口，支持 GUI、命令行及串口服务器的字节流收发。
- 支持双向并发收发、断开后重新打开；关闭连接时取消等待中的读写，避免卡住。
- 端口占用或 VirtualCOM 退出时提供明确提示；失效的端口不加入可用列表。
- 界面显示「免驱动」及串口参数不生效的说明；修复刷新时丢失端口选择、历史连接回填导致参数无效的问题。
- 原始数据继续保存至 SQLite，物理串口保持原有连接方式。

## 使用

先运行 `VirtualCOM-GUI.exe` 创建一对端口并保持运行，再打开两个 CommBox 窗口，分别连接两端。命令行使用 `CommBox-CLI.exe -list` 查看端口、`-port COM号` 打开。

## 验证与边界

- 在 Windows 11 build 26200 验证两组真实 VirtualCOM 配对、四个方向各 1 MiB 并发传输、任意字节值、重复开关和退出清理；全量 Go 与 Windows GUI 回归测试通过。
- 此适配仅让 CommBox 使用 VirtualCOM 字节流端口，不提供标准串口 API。波特率、数据位、校验、停止位和控制信号不生效；未适配的第三方串口软件仍不兼容。
- VirtualCOM 必须保持运行并与 CommBox 位于同一用户登录会话；退出后端口会移除。Windows 10 和长时间运行尚未验收。
- 程序未做商业代码签名。
