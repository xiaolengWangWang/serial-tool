# CommBox v0.7.0 功能优化方案

## 目标

在不影响收发稳定性的前提下，增加“本地报文分析 + 可选 AI 辅助”，macOS、Linux 和共享核心保持一致；Windows 暂不纳入本版本。

## MVP 范围

### P0：本地报文分析

- 当前报文、选中报文、最近 20 条报文
- TCP/UDP 应用层负载分析
- IPv4 TCP/UDP 头识别：协议、源端口、目的端口
- Modbus RTU：从站、功能码、异常码、起始地址、数量、CRC
- Modbus TCP：事务标识、单元号、功能码、长度
- 结果显示：正常 / 警告 / 异常
- 原始 HEX 永远保留，分析失败不能阻断收发

### P1：异常检测

- CRC 错误
- Modbus 异常响应
- 请求无响应和响应超时
- 报文长度异常
- TCP/UDP 连接断开

### P2：DeepSeek 可选增强

- 默认关闭、默认 Key 为空
- 默认不调用、不上传数据
- 仅用户点击“AI 辅助分析”后请求
- 请求前显示数据范围和脱敏预览
- API 地址、模型、超时、最大数据量可配置
- macOS Keychain 保存 Key；Linux 配置文件权限 600
- 网络失败只提示，不影响本地分析

## GUI

接收数据页增加：

```text
分析选中 | 分析最近20条 | 本地分析 | AI 辅助分析
```

分析结果独立显示以下字段：

```text
协议 / 方向 / 长度 / 功能码 / 地址 / 数量 / CRC / 状态 / 建议
```

右键菜单保留“本地分析”和“复制 HEX”，不改变原始数据。

## 开发顺序

1. Modbus RTU/TCP 解析和测试
2. TCP/UDP 头识别和测试
3. 当前/选中/最近报文 GUI 入口
4. 异常检测
5. DeepSeek 配置、脱敏和显式调用
6. macOS Universal、Linux 构建和模拟设备验收

## 安全约束

- 禁止把 API Key 写入源码、测试、日志和 Git
- API Key 已在聊天中暴露时必须撤销并重新生成
- AI 功能未启用时不得创建请求
- 单次请求限制 16 KB，超出时提示用户选择筛选范围

## 验收标准

- 离线状态下 P0 功能全部可用
- 标准 Modbus RTU CRC 测试通过
- Modbus TCP MBAP 长度和字段测试通过
- TCP/UDP 端口识别测试通过
- 分析失败不影响继续收发
- DeepSeek 默认关闭且 Key 为空
- macOS arm64/amd64、Linux amd64 构建通过
- 发布包仅包含 macOS 与 Linux

## 非目标

- Windows 同步开发
- 默认上传通信数据
- 自动持续调用 AI
- 云端历史数据存储
- 复杂协议的无规则自动推断
