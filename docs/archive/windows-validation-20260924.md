产物及全部压缩包校验值位于 `build/CommBox-optimized-Windows-x64*` 和 `build/size-review/packages.json`。

## 功能验证

开启 `COMMBOX_GUI_TEST=1`、`COMMBOX_VIRTUALCOM_TEST=1`，执行 `go test ./... -count=1 -json`：三个包通过，共 **152 个测试及子测试通过，2 个跳过**。跳过的是缺少符号链接权限的用例及未启用在线下载的更新测试。

VirtualCOM 实际创建两对免驱动端口，完成双向并发 1 MiB 传输和重复打开测试。测试记录：`build/gui-test-20260924/go-test.jsonl`。

从最终 GUI 7z 解出主程序，在独立临时用户数据目录运行，**61 项 GUI 操作检查通过**：

- 紧凑窗口、最大化、AI 面板展开与收起、各连接模式及工具窗口入口。
- HEX 输入验证、筛选、选择统计、本地分析、定时与循环发送。
- TCP 客户端回显、服务端多客户端广播、定向发送隔离、文本 CRLF 和发送后清空。
- UDP 客户端收发及拒绝非配置目标；服务端最近对端回复、选择对端和指定地址发送。
- HTTP 主界面与工作台请求、Cookie 会话、JSON 响应显示。
- 快捷报文保存、回填、删除，发送历史及托盘恢复。

测试结果与截图位于 `build/gui-test-20260924/`，最终完整执行日志为 `final-run.log`，逐项结果为 `click-results.json`。

早期自动化运行曾出现一次 TCP 切换 UDP 后未就绪，原因尚未确定；之后扩展复测与最终解压程序的完整复测均通过，未据此修改产品代码。
