本稿的文字与布局规则

参数就近说明
标签固定在输入框上方；单位放在数值旁。基础参数常驻，高级参数折叠。占位文字只放例子。

操作层级明确
连接、发送使用主按钮；验证、导出使用次按钮。隐藏内容不停止任务，运行状态与停止入口应保持可见。

错误能直接处理
先说明哪里出错，再给修复建议。原始技术详情按需展开，避免长错误挤压参数和报文。
