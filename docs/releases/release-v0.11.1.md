# CommBox v0.11.1 — 聊天式 AI、视图设置与完整使用手册

Windows 主页面默认简洁显示，高级操作按需展开；本版同时提供 macOS Apple Silicon / Intel 与 Linux amd64 / arm64 构建。

## Windows 下载选择

- 日常桌面使用：GUI.zip 约 7.18 MiB，或 GUI.7z 约 5.50 MiB，包含 CommBox 主程序、内置虚拟串口管理及完整离线手册。
- 需要命令行或独立 VirtualCOM：下载完整 ZIP（约 14.49 MiB）或完整 7z（约 7.00 MiB）。
- 压缩包内的程序与原发布文件逐字节一致。主程序 7z 下载体积减少约 62%；EXE 本身体积不变。
- 7z 包需要支持该格式的解压工具；优先兼容性时选 ZIP。

## Windows 操作体验

- AI 改为聊天式：输入问题、添加多个附件、点击发送；Enter 换行，Ctrl+Enter 发送。
- 报文可选附带，未勾选时不会自动加入主界面数据；“分析选中”先准备草稿，点击发送后再提交。
- 本地检查独立运行，不因启用 AI 而自动上传；收起 AI 面板时回答继续。
- 新增“查看 → 视图设置”，选择显示连接、数据、日志、发送和 AI 区域，保存后下次启动保留。
- 高级发送选项默认收起，统一输出框背景、按钮与复选框间距，补充复杂功能提示。
- 常见文件、串口和网络错误优先显示中文解释，保留原始技术详情。

## 完整离线手册

- Windows 在“帮助 → 完整使用手册”或 F1 打开，可按章节阅读并搜索标题与正文。
- 覆盖连接、收发、筛选、导出、定时与循环、桥接、HTTP、校验、历史、AI、多附件、虚拟串口、CLI 与故障排查。
- Windows ZIP、macOS 应用资源和 Linux 压缩包均附带手册；macOS 帮助菜单可用系统文本编辑器打开。
- 明确平台差异、历史清理规则、AI 上下文范围和虚拟串口兼容限制。

Windows VirtualCOM 继续使用独立项目 v0.2.3 的共享实现。Windows 本轮界面改动不改变 macOS 聊天布局或 Linux 命令行功能。真实外部 AI 服务需使用自己的配置；本地自动化验证使用模拟服务。

各平台测试及构建全部成功后发布，校验值随产物提供。
