# CommBox v0.11.2 — Windows 页面布局优化

本版落实已确认的 Windows 页面布局，同时提供 macOS Apple Silicon / Intel 与 Linux amd64 / arm64 构建。

## Windows 页面与交互

- 常规窗口支持连接配置、数据与发送、AI 助手三栏并排；小窗口按空间切换分区。
- 连接参数名称放在输入框上方，单位紧邻数值，数据位和校验位并排；自动重连设置按需展开。
- 顶部提供 AI 助手、视图设置及使用手册入口；较矮屏幕仍可通过菜单访问。
- 发送区依次排列格式与目标、输入框与发送按钮、提示与发送后清空；历史、快捷、定时和循环在“更多发送”中展开。
- AI 对话记录优先展示，附带报文与附件靠近问题输入框，设置移至面板顶部。
- 连接、报文发送和 AI 发送按钮使用蓝色主操作样式，保留原生键盘操作与焦点提示。
- 数据显示格式移入“更多筛选”；全选、取消选择、反选移入表格右键菜单；数据区导出按钮直接导出 CSV。
- 完整离线使用手册同步更新。

## 下载选择

- 日常 Windows 桌面使用可选 GUI.zip 或 GUI.7z：包含主程序、内置虚拟串口管理及手册。
- 需要命令行或独立 VirtualCOM 时选完整 ZIP / 7z。压缩版不改变可执行文件内容。
- macOS 提供 Apple Silicon / Intel DMG；Linux 提供 amd64 / arm64 程序及含手册的压缩包。

各平台测试和构建通过后发布，SHA256 校验值随产物提供。Windows 布局更新不改变 macOS 界面或 Linux 命令行功能。
