# CommBox v0.9.18

本版提供 Windows x64、macOS Apple Silicon / Intel 安装包和 Linux amd64 命令行程序。macOS 的 AI 深度分析改为流式对话；Windows 和 Linux 的功能与上一版本一致，版本号同步到 0.9.18。

## 本版变化

- macOS 的 AI 深度分析在独立的「AI 数据分析对话」窗口中进行。确认发送范围（当前报文、选中报文或数据库报告）后，回答边生成边显示。
- 回答过程中可点「停止」，已生成的部分会保留。可在同一窗口继续追问，「新对话」清空上下文。
- 对话内容自动保存为本地 Markdown 文件；数据只在点击发送后上传。
- macOS 对话窗口暂不支持附件，附件功能目前仅 Windows 提供。

## 验证与边界

- macOS 上全量 Go 测试、原生桌面构建通过；AppKit 布局自检检查 488 个界面组合（含浅色 / 深色 AI 对话窗口），0 个失败。
- Windows x64 交叉构建通过，版本资源已同步。此构建环境没有 Windows 桌面，Windows 程序未做原生界面验收。
- 版本资源、安装包内容和 SHA256 校验值以发布产物为准。程序未做商业代码签名；macOS 使用临时签名。
