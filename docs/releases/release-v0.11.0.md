# CommBox v0.11.0 — Windows GUI 美化与交互优化

本版重点优化 Windows 桌面体验，同时提供 macOS Apple Silicon / Intel 原生桌面包，以及 Linux amd64 / arm64 命令行程序。

## Windows 界面与图标

- 重新设计应用图标与操作图标，统一蓝青配色、线宽和圆角，提供多尺寸 Windows 图标资源。
- 菜单增加功能图标，统一分区标题与辅助文字颜色；AI 分析范围增加明确标签。
- AI 附件区改为可见列表，显示当前数量，可多选或分批添加最多 6 个附件，并逐项移除。
- 重复选择同一路径时跳过重复文件；不同目录下同名文件仍可分别添加。
- 单个附件读取失败不再取消整批添加，保留有效附件并提示失败文件名；超出数量上限时保留前 6 个有效文件。
- 附件仍在本地异步读取，点击发送才上传；发送失败或停止时恢复待发送内容与附件。

## 虚拟串口管理

- 在「工具 → 虚拟串口管理」直接创建和管理端口，共用独立 VirtualCOM 项目的核心与界面。
- 调整创建区、列表与操作区的文字层级，显示当前选中的串口对，并支持复制两个端口名。
- 更新 VirtualCOM 图标与高 DPI 资源；重复打开窗口复用标题栏图标，避免资源累积。
- 首次进入管理页时清理失效的历史端口映射。关闭管理页后通信继续，退出创建端口的程序后端口释放。

## 平台与使用说明

- Windows x64 完整 ZIP 包含 CommBox GUI / CLI、VirtualCOM GUI / CLI 及说明文档。
- macOS 分别提供 Apple Silicon 与 Intel DMG；本轮 AI 附件交互改动仅适用于 Windows。
- Linux 提供 amd64 / arm64 命令行程序和保留可执行权限的 tar.gz 压缩包。
- Windows VirtualCOM 仅兼容已适配的字节流应用，波特率等串口参数不生效；macOS / Linux 使用原有 PTY 方案。
- 程序未做商业代码签名；macOS 使用临时签名。真实外部 AI 服务需使用自己的服务配置验证。

各平台产物由同一提交构建，测试和构建全部成功后发布，文件校验值附于下方。
