# CommBox v0.11.6 — 高频通信存储性能优化

本版减少高频小报文入库时重复读取数据库、WAL 和共享内存文件大小的开销。串口、TCP、UDP 和后台虚拟串口共用此优化，仍然同步逐条保存原始字节及会话信息。

## 优化

- 数据库大小检查最多复用 32 次写入或 250 毫秒；下次写入达到任一条件时重新读取实际文件大小，不增加后台定时任务。
- 根据报文大小预留原始数据、文本、SQLite 页面、索引及 WAL 的增长空间。接近文件大小上限、大报文或较大元数据时立即读取实际大小。
- 跨日期、更换数据文件以及插入或结束会话时重新检查大小，保持主连接和后台虚拟串口的记录归属。
- 缓存有效期使用实际时钟，避免历史报文时间影响检查周期。

## 验证

- 增加真实 SQLite 测试，验证三条写入路径在日期滚动后保留原始字节及会话归属，以及额外数据库增长能在 32 次写入内触发轮换。
- 增加大元数据写入后的回归测试，确保下一条小报文重新检查实际文件大小。
- Windows 本机全套测试及 `go vet ./...` 通过；GUI 和命令行程序均已构建并核对版本资源为 0.11.6。正式发布通过各平台原生环境测试及构建后生成安装包和 SHA256 校验清单。
- 新增 `BenchmarkStoreRecord`。本机 Windows x64、7 字节报文、三次 1 秒基准中，优化前耗时为 1.09–1.27 毫秒/条，优化后为 0.16–0.29 毫秒/条；每条内存分配从 40 次降到 33 次。结果受磁盘、杀毒软件和系统负载影响，不代表所有通信场景的端到端速度。
