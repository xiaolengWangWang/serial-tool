# CommBox v0.9.16

Windows x64，解压后运行 `CommBox.exe`。发布包附带 VirtualCOM v0.2.2 的图形界面和命令行，无需安装虚拟串口驱动。

## 本版变化

### AI 分析改为流式对话

- AI 回答边生成边显示，不再等待整段完成；超时按「多久没有收到新内容」计算，持续生成的长回答不会被总时长截断。
- 回答期间「发送」变为「停止」。停止后保留已经生成的内容，可继续提问。
- 分析结果和后续追问按时间排列在同一段对话中，不再覆盖上一次结果；支持复制最近回答、清空对话和导出完整记录。
- 右侧 AI 面板和历史数据分析窗口共用同一套对话组件、服务配置与启用状态。
- 主面板可直接选择当前报文、最近 100 条或历史数据库最近 5 / 30 / 60 分钟进行分析。

### 分析准确性与可用性

- 疑似 Modbus RTU / TCP 帧由程序附加本地解析，包括从站或单元、功能码、地址、字节数及 CRC 是否通过；提示词要求 AI 与本地解析冲突时以程序计算为准。
- CRC 错误会同时显示收到值和应有值；普通文本或不像 Modbus 的数据不会被误标成 Modbus。
- 历史数据库报告超过 32 KiB 时自动保留概要和前部明细，并明确注明后续内容已省略，不再直接拒绝分析。
- API Key 无效、余额不足、限流、服务繁忙和网络连接失败会显示更具体的原因。
- 支持 OpenAI 兼容服务的 SSE 流式响应，也兼容仍返回完整 JSON 的服务。

## 隐私说明

AI 默认关闭。本地分析不会上传数据；只有用户在设置中启用 AI 并主动开始分析或发送问题时，才会把所选报文、报告和当前对话发送到配置的服务。API Key 保存在 Windows 凭据管理器中。
