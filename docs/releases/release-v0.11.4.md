# CommBox v0.11.4 — 维护版本

本版没有功能变化，用于确认从 v0.11.3 起的软件内更新：装着 v0.11.3 的 Windows 版点击“帮助 → 检查更新”，会从 Gitee 下载本版并在软件内完成安装。

## 变更

- 修复 Gitee 镜像同步脚本在 Windows PowerShell 5.1 下推送失败和附件核对报错的问题，只影响发版流程，不影响软件本身。

## 下载

- 国内推荐 Gitee：https://gitee.com/sun_xuanqi/serial-tool/releases ，安装包和校验值与 GitHub 相同。
- 日常 Windows 桌面使用可选 GUI.zip 或 GUI.7z；需要命令行或独立 VirtualCOM 时选完整 ZIP / 7z。
- macOS 提供 Apple Silicon / Intel DMG；Linux 提供 amd64 / arm64 程序及含手册的压缩包。

## 注意

v0.11.2 及更早版本只从 GitHub 检查更新，升级到本版仍走原来的下载流程（下载后关闭 CommBox 解压覆盖）。
