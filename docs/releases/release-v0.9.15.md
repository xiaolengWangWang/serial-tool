# CommBox v0.9.15

Windows x64，解压后运行 `CommBox.exe`。发布包附带 VirtualCOM v0.2.2 的图形界面和命令行，无需安装虚拟串口驱动。

这是 v0.9.4 之后的第一个 Windows 版本。v0.9.5 至 v0.9.14 只发布了 macOS 安装包，其中适用于 Windows 的修复都包含在本版中。

## 本版变化

### 界面：数据区更大

- 任何缩放比例下，数据表那一栏都占「数据 + 发送」合计高度的 70% 以上，中栏占窗口宽度的 70% 以上。最紧的 1024×552 可用区域（1600×900 @150%、1366×768 @125% 等），数据表从 4~6 行增加到 8~9 行。
- 数据表与发送区之间去掉了可拖动的分隔条，发送区固定占 30%。窗口较矮时（例如 1366×768 屏幕、150% 缩放的 1080p 屏幕），「历史 / 快捷」与「定时 / 循环」两行收进发送区首行的「更多发送」按钮；收起时如果定时或循环仍在进行，按钮显示「定时中」或「循环中」。发送框最少 3 行。
- 左侧连接栏从 270~280 收窄到 240~250，端口、IP、最近连接下拉框不再按最长选项撑宽。打开 AI 面板时，窗口宽度不足 1954 会先收起连接栏。
- 筛选压成一行：搜索、方向、显示方式、「更多筛选」「重置筛选」和计数。连接 ID、协议、时间收进「更多筛选」，收起时条件仍然生效，按钮显示「筛选已启用」。
- 数据表、日志、发送框和监控窗口的报文改用 12pt 等宽字。HEX 与 ASCII 两列按表格宽度和显示方式分配剩余宽度，方向列按收发着色。
- 发送历史、快捷名称再长也不会把窗口撑出屏幕，展开的列表至少 360 像素宽。
- 状态栏前显示当前模式的图标。验证与发送结果提示移到发送区首行，UDP 地址与发送目标并排。

### 连接与数据

- TCP 客户端首次连接与虚拟串口拨号加 10 秒超时。此前目标不通时，窗口要卡约 75 秒。
- 断开日志里的收发字节和帧数只统计本次连接，不再带上之前各次连接的累计。
- 对端关闭、TCP/UDP 监听出错引起的断开，不再误记为「用户在本程序上断开」。
- 虚拟串口的数据在数据库文件轮换（跨零点或满 100 MB）时不再记到错误的会话上。
- 定时发送：停止的同时不再多发一次；停止或断开后晚到的失败不再弹窗，也不会误停新开的定时器。
- 开启时间过滤时，报文表不再每秒重置，选中行与滚动位置保留。

### HTTP 与 cURL

- HTTP 响应正文最多读取 64 MiB，超出部分截断并提示；每次请求用完的连接池及时关闭。
- cURL 导入支持 Chrome「复制为 cURL」的 `$'...'` 写法、`-sSL` 这类组合短选项和 `--json`，忽略 `--compressed`、`-s`、`-S`、`-i`、`-v`。以 `-` 开头的选项值（如 `-d '-sort=asc'`）不再被误拆成选项。

### 工具与其他

- 工具箱新增 HEX↔文本、HEX↔十进制（大端 / 小端、有符号）、十进制→HEX。Unix 时间戳 13 位及以上按毫秒解释，结果可以选中复制。
- AI Key 改存 Windows 凭据管理器，旧版本存下的明文值在首次读取时自动迁移。
- 报文分析的字节序候选固定按 ABCD、BADC、CDAB、DCBA 的顺序输出。
- 启动时的自动检查更新，只在新版本带 Windows 安装包时才提示。此前 macOS 单独发版后，Windows 每次启动都会提示一个下载不了的更新。
- VirtualCOM 0.2.2：清空缓冲区时一并丢弃待送达的数据；`ports` 的编号排序修正；关闭控制台窗口、注销、关机时也会拆除端口。

## 使用

先运行 `VirtualCOM-GUI.exe` 创建一对端口并保持运行，再打开两个 CommBox 窗口，分别连接两端。命令行使用 `CommBox-CLI.exe -list` 查看端口、`-port COM号` 打开。

## 验证与边界

- 全量 Go 与 Windows GUI 回归测试通过，其中包括真实 VirtualCOM 双端口传输。发布产物逐项校验 PE 头、构建来源 commit、版本资源和压缩包内容。
- 布局测试在真实窗口上模拟 9 种屏幕与缩放组合，新增两项检查：数据栏占比和中栏占比都不低于 70%；另外检查发送框至少 3 行、数据表至少 3 行、控件不重叠不裁切。
- 测试机为 2560×1600 @175%，另用 DPI 无感知模式模拟 100% 缩放。1920×1080 @100% 和 @125% 按折算尺寸比测试机屏幕大，没有实测。
- 用户手动展开「更多筛选」或「更多发送」时按展开内容排版，数据栏占比可能低于 70%。窗口被手动拖到很矮、数据与发送合计高度不足约 365 逻辑像素时，也无法保证 70%。
- VirtualCOM 适配的边界与 v0.9.0 相同：只提供字节流端口，波特率、数据位、校验、停止位和控制信号不生效，未适配的第三方串口软件仍不兼容。
- VirtualCOM 必须保持运行，并与 CommBox 位于同一用户登录会话；退出后端口会移除。Windows 10 和长时间运行尚未验收。
- 本版只含 Windows 安装包。macOS 版仍为 v0.9.14，手动检查更新会看到 v0.9.15，但没有 macOS 安装包可下载，启动时也不会自动提示。
- 程序未做商业代码签名。
